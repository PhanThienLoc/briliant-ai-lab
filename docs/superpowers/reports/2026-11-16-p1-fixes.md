Scope approved by user: B01, B02, B03 in the 2026-11-16 v38 QA report. Base source: `40527f93425397d6f0515e013ff7d13373eebef9`.

## Changes

- Backup parsing reuses the existing lesson payload shape validator, with strict integer/nonnegative index checks and catalog bounds for known lessons. Invalid imports fail before restoration writes.
- Local progress normalization clamps finite indices to integer activity bounds. Stage selection also has a first-activity fallback.
- The repository's local shape check retains finite-index compatibility: a corrupt fractional/negative/overflow local index must not erase otherwise valid completion, evidence or review dates from its snapshot. New preservation tests verify original stored bytes remain untouched.
- SQL ordinary NULL comparisons yield UNKNOWN; WHERE/HAVING discard it and JOIN equality requires true.
- Aggregates resolve column identity from the schema/sample row even when a group is empty. COUNT returns 0 and SUM/AVG/MIN/MAX return NULL for empty/all-NULL inputs, rather than undefined or SUM=0.
- Validation on the same projection path also rejects unknown columns on empty results and wildcard aggregates other than COUNT.
