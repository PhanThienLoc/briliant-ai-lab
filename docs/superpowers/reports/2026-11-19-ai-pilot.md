# AI teaching pilot
User decisions: provider keys entered in Settings; free usage only; explicit review of source payload before every request; train/validation/test and leakage as first subject; Vietnamese teaching, visual steps, Python practice, tutor questions and delayed transfer.

Implements OpenRouter free router with zero-price provider limits and no paid fallback, plus Gemini2.5Flash-Lite with an explicit project FreeTier/no-billing declaration. The app cannot verify Gemini billing from a key. Other/custom endpoints are not enabled. Provider keys remain in tab memory and are transmitted transiently through a fixed same-origin route, never stored in course data or Passport.

Selected1–3 source sections (<=12k chars) are previewed with the complete prompt and destination before consent. Generation is one request, no automatic retries; cancel and stale source/config checks discard old results. Generated structures, answer bounds and selected-source quote references are validated before a human-review save. Exact quotes do not prove entailment or teaching quality.

Saved lessons offer prediction, explanations, worked examples, numbered visual steps, text-only Python starter/solution, first check,72h gated transfer and source-bound tutor questions with per-send consent. Model-generated code/HTML is not executed. AI courses and learner progress are separate and included in Passport. This pilot is not whole-book generation, a validated learning-outcome trial or integration of AI review into the shared Hub.

Verification: strict typecheck, content audit, production build and308/308 tests pass. Provider responses use mocked fetch; no API key provided and no live generation performed. Read-only independent review found no blocker; capacity delete action added. Lint has zero errors and3 existing generated-worker warnings. Managed browser preview was rejected by automatic approval review because it may disclose source to workers.cloudflare.com; no workaround was attempted. Browser UI and real-provider content quality remain unverified.
