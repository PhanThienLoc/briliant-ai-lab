# Curriculum map

## Full sequence

0. Diagnostic, learning method, and problem framing.
1. Logic and discrete mathematics.
2. Mathematics for AI: algebra, linear algebra, calculus, optimization, probability, and numerical computing.
3. Programming and software engineering.
4. Algorithms and data structures.
5. Computer systems foundation.
6. SQL and database systems.
7. Statistics, experimentation, and causal thinking.
8. Data Science and classical machine learning.
9. Data Engineering.
10. Deep learning.
11. ML systems, MLOps, and cloud.
12. LLM and agent engineering.
13. Responsible AI, security, privacy, and governance.
14. Specializations: time series, recommender/search, NLP, CV, graph ML, RL, anomaly detection, geospatial, and multimodal AI.

Technical English, communication, systems thinking, and career transfer run across every stage.

4. Functions as transformations.
5. Vectors and dot products.
6. Linear prediction.
7. Residuals.
8. Mean Squared Error.
9. Derivative as sensitivity.
10. Gradient.
11. Learning rate and gradient descent.
12. Linear regression from scratch.
13. Validation and overfitting.
14. Capstone: raw CSV to evaluated model.

## Content production gate

Every lesson must define:

- prerequisites and observable outcomes;
- likely misconceptions and edge cases;
- pretest and interactive representation;
- independent and transfer problems;
- code/data/system application;
- deterministic scoring;
- delayed and mixed-practice variants;
- source metadata and copyright-safe original explanation.

AI-generated lesson drafts are never published without human review.
