# Source Studio three-step checkpoint

- Source input, coverage selection and review are separate visible steps.
- Returning through steps retains source text and section selections; editing source invalidates dependent drafts through the existing reset path.
- Native practice stays local. AI review uses its existing exact-payload consent. Leaving the AI step cancels the wait, invalidates response tokens and resets send consent, including source tutor follow-up requests. Providers may already have received a canceled request; no automatic retry occurs.
- Saved coverage and AI courses remain accessible from the first step. Native practice drafts reopen in review.
- Keyboard focus moves to the Studio heading on step changes; source extraction page-range fields disable while busy.
- Browser checked: input two Markdown sections, select both, create native review, return with both selections intact, open AI review without transmitting data.
- Real AI key calls, Android and complete multi-viewport QA were not performed. File/link/paste method-specific input forms remain a later refinement.
- No storage schema or grader changes; Rust remains unintegrated pending evidence of a CPU bottleneck.
